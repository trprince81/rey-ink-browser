# Rey ink - Actualizador

Agente de navegador para Rey ink. Esta carpeta es independiente del panel web.

## Objetivo
- Mantener un panel fijo dentro de la página objetivo.
- Recibir órdenes del Control Center.
- Mantener un estado local del dispositivo.
- Ejecutar solamente acciones explícitamente habilitadas por el usuario.

## Seguridad
No contiene credenciales ni datos de terceros. No modifica `main`.
